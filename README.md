## Projet de Machine Learning

Projet réalisé en équipe dans le cadre d’un cours pendant mon semestre d’études à l’Université de Shanghai.

On a comparé plusieurs méthodes de réduction du bruit pour voir si elles amélioraient la transcription avec Whisper. Dans nos essais, le filtre de Wiener aidait avec du bruit blanc, mais augmentait les erreurs avec des bruits de rue ou des conversations en arrière-plan. On a aussi étudié l’effet du filtrage sur la reconnaissance des émotions dans la voix.
